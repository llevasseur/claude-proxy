# The docs gate asserts section indexes by file, and permits links out to source

## Status

Proposed by `/dev` during the `monorepo-fusion` campaign. A human has not ratified it.
Not flagged `needs-human`: it repairs a gate against measured output. `grill-round: 0`
records that this came from `/dev`'s own verification rather than from a griller round.

## Context

Blocker (h) said to run `check-docs.mjs` against claude's never-link-checked docs
**before** wiring it into `check`, and to relax the containment rule if those docs
legitimately link out to source. That was run rather than assumed. Codex's script,
pointed at claude-proxy's 62 documents, fails with **exactly five errors**:

- **0 genuinely broken links.** claude's bundle is clean.
- **1 containment violation**: `docs/features/ideas-ledger.md` links to
  `../../services/concepts/README.md` — a legitimate link out to source, exactly the case
  the blocker anticipated.
- **4 missing index assertions**: the script requires `docs/index.md` to contain the
  literal `(adrs/index.md)`, `(features/index.md)`, `(specs/index.md)`,
  `(roadmap/index.md)`.

The fourth is not what the blocker assumed. claude's `docs/index.md` is **generated by
okq** between `okq:index:begin` and `okq:index:end` markers, and okq emits directory
links — `[adrs/](adrs/)` — not `(adrs/index.md)`. Adding those links by hand would fight
the generator on the next run. claude also has no `docs/roadmap/` at all (it arrives with
ox) and does have a `docs/wayfinder/` the assertion does not check. Separately,
ox-alpha-proxy has **no `docs/index.md`**, which is why its rewrite dropped the assertion
rather than fixing it.

## Decision

**The gate asserts each section index exists as a file, not that the root index links to
it in a particular literal form.** `existsSync(join(docsRoot, section, 'index.md'))` is
what the assertion was reaching for; the string grep was a proxy for it that okq's output
format does not satisfy.

**The containment rule is relaxed to permit links that resolve to a tracked file inside
the repository, and continues to reject links that resolve nowhere.** The distinction the
rule should draw is between a link that works and one that does not — not between a doc
that stays inside `docs/` and one that points at the source it documents. Codex's version
conflates them, which is why it reports a working link as an error.

**The checked section list is derived from the directories present, not hardcoded.** The
merged bundle has `adrs/`, `features/`, `specs/`, `roadmap/` (from codex and ox) and
`wayfinder/` (from claude). A hardcoded list is wrong for at least one stack in every
arrangement.

## Consequences

- The gate can be wired into `check` on the merged tree without a flag day, and codex's
  containment check and index assertion — the two things its version has that ox's
  rewrite dropped — are preserved in intent rather than in letter.
- ~~ox's bundle needs a `docs/index.md` created before the gate runs against it.~~
  **Moot.** ox's bundle no longer exists: it was folded into the root bundle along with
  codex's, and the per-stack `check-docs.mjs` scripts were deleted with the trees they
  walked. There is one bundle and one gate, at the root.
- Measured, not predicted: claude's 62 documents contain zero broken links, so the
  bundle's link health was never the risk here. The gate's own assumptions were.
- **Re-measured against the merged bundle when the repair was implemented**, because the
  corpus had more than doubled since — 142 documents, not 62. The count went from five
  errors to **seven**, and the two new ones are a fourth defect in the gate rather than a
  fourth defect in the docs: this record and one campaign plan each *quote* the generated
  link form `[adrs/](adrs/)` in prose to explain it, and the scanner read those
  quotations as links and resolved them relative to the quoting file. **So the gate also
  blanks fenced blocks and inline code spans before scanning.** A document that quotes a
  link as an example is not linking anywhere, and reading it as one made a record about
  links unable to describe one.

## Provenance

Decided in this repository during `monorepo-fusion`, from running
`codex-proxy/scripts/check-docs.mjs` against `claude-proxy/docs/` before adopting it.
Preserves the containment check and index assertion that ox-alpha-proxy's rewrite
dropped.
