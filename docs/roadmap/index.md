# Roadmap

Delivery ladders — the ordered outcomes a stack ships, each independently useful. List
them:

    okq find --type roadmap

## Two ladders, both true

`codex` climbs five rungs and `ox-alpha` climbs four. That is not a disagreement to
resolve: [ADR 0021](../adrs/0021-outcome-ladder.md) fixes the ladder as one decision with
a per-stack rung count, and every document here carries `scope` saying which stack it
governs. [Four rungs to Plane](four-rungs-to-plane.md) is the only record explaining
ox-alpha's shape, which is why it survives the merge intact rather than being folded into
codex's.
